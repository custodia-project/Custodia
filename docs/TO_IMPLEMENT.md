## Orden vigente de implementación

Dirección del 16/11: primera alfa autohospedada en una sola instancia,
backend Go con SQLite embebido y frontend existente. PostgreSQL deja de ser
requisito de instalación. El laboratorio inicial no es una descarga productiva.

1. Reconciliar contratos de Personas/cobertura con Python y avanzar el laboratorio Go.
2. Autorizar operaciones por usuario y conexión; integrar el frontend contra Go.
3. Persistir registros, corridas y decisiones; validar dos conexiones aisladas.
4. Primer conector de lectura y segunda fuente para comprobar un cruce real.
5. Binario con frontend, configuración inicial, actualización, backup/restore y piloto.

Las filas históricas de UI/sitio siguientes no son evidencia de estado actual:
